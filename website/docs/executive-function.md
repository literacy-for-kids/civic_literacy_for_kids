# Executive Function Skills for Civic Life

Civic life includes group work, roles, meetings, proposals, voting steps, public problems, and follow-through. Executive function helps kids organize shared work and participate responsibly without getting overwhelmed.

This page is the local doorway into the Literacy for Kids [Executive Function Toolkit](https://www.literacy-for-kids.com/docs/toolkits/executive-function), connected to the civic understanding this curriculum builds.

## A few core ideas

- **Shared work needs visible roles.** "Who is doing what?" keeps a group moving.
- **Civic proposals need steps and deadlines.** A plan with dates is easier to follow.
- **Prioritizing helps groups decide what to do first.** Not everything can be first.
- **Restart points help long projects continue.** Big efforts pause and resume.

## When this shows up

- When a group needs roles
- When planning a classroom or community proposal
- When voting or decision steps are confusing
- When a project has many people
- When a meeting creates next steps
- When a shared problem feels too big

## Tools that help

- **Role checklist** — who does what.
- **Proposal checklist** — the steps to build a proposal.
- **Must / should / could** — for group priorities.
- **Next-step tracker** — what happens after the meeting.
- **Restart bookmark** — so the next session picks up easily.

:::tip Executive Function Moment
A group project needs visible next steps. Before the meeting ends, write: "Who is doing what, and by when?" That small checklist helps shared work keep moving.
:::

:::caution Everyday task skills, not a diagnosis
These are everyday planning and task-management tools, not therapy, medical advice, disability evaluation, ADHD treatment, or a replacement for trusted adults, educators, caregivers, or qualified support. Kids should not be treated as lazy or broken when starting, focusing, organizing, or finishing is hard. If tasks feel consistently overwhelming, inaccessible, unsafe, or severely distressing, involve a trusted adult and appropriate support.
:::
